
# ComicCraft - AI Comic Story Creator using Gemini Models
A generative AI application that creates comic stories with images using Google Gemini.

### Features
- Generate comic story from text prompt
- Create comic images using Gemini
- Java + Python backend

### Tech Stack
- Gemini API, Python, Java, Javascript

### How to Run
1. Clone repo
2. Add Gemini API Key
3. Run app.py / app.java
